# My Pocket Dictionary

An Android dictionary application built with Android Studio and Kotlin that allows users to discover a Word of the Day and search for word definitions using external REST APIs.

## Team Members

- Raymond DiDonato
- Razan Shams
- Jack Del Rosario

## Project Overview

My Pocket Dictionary allows users to view a Word of the Day on the home screen and search for words and retrieve definitions organized by part of speech. The app includes error handling for invalid searches and supports both portrait and landscape orientations.

## Tech Stack

- Development Environment: Android Studio
- Programming Language: Kotlin
- UI: XML
- Networking: Volley
- APIs: Word of the Day API, Free Dictionary API
- Data Format: JSON
- Architecture: Android application using API-driven data

## Setup Instructions
### Requirements
- Android Studio
- Android SDK
- Built-in Emulator or Android device
- Internet connection
### Steps
**1. Install Android Studio**

  - Download and install Android Studio.

  - Open Android Studio and make sure the required Android SDK components are installed.

**2. Clone the Project**

  - Clone or download this repository.

  - Open Android Studio and select:

  - File → Open

  - Select the project folder and allow Gradle to sync the project.

**3. Internet Permission**

  - Make sure the Android manifest contains the required internet permission:

  -  android:name="android.permission.INTERNET" 

**4. Run the Application**

  - Connect an Android device or start an Android Emulator.

  - In Android Studio, select the desired device and click:

  - Run ▶

  - The application should launch on the selected Android device or emulator.
